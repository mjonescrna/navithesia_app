# NavisThesia Web Portal - Student Interface

This folder will contain the Flutter Web-based student interface for the NavisThesia platform.

## Planned Features

- Web version of case logging functionality
- Enhanced reporting and analytics
- Student-to-student messaging
- Communication with school administrators
- Profile management
- Transcript generation
- Hospital culture insights

## Technology

- Flutter Web (shared code with mobile app where possible)
- GraphQL client
- Responsive design for desktop/tablet/mobile
