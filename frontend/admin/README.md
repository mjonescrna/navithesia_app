# NavisThesia Web Portal - Admin Interface

This folder will contain the React-based administrative interface for the NavisThesia platform.

## Planned Features

- School administrator dashboard
- Student roster management
- Cohort creation and management
- Reporting system
- Hospital culture analytics
- Clinical site management
- Messaging center
- Owner-level system administration

## Technology

- React
- Material UI
- GraphQL client
- Chart.js for analytics visualization
